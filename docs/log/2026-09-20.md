## Milestone 2 — real terrain (mostly done)
- `scripts/fetch-dem.ts` (`npm run world:dem`): Copernicus GLO-30 COG read over
  HTTP with `geotiff`, resampled to a grid. Pure Node (no GDAL/osmium).
- Scope narrowed to **Chittagong city** (ADR-0007): 549×668 @ 30 m, 1.5 MB,
  elevation −0.95 … 543.1 m. Origin recentered to bbox center.

- Fixed back-face culling: terrain triangles were wound backwards.
- Water deferred. Sea-level-derived water flooded the low coastal plain and
  z-fought with terrain; removed. Correct approach = OSM water polygons.

## Milestone 3 — real roads (done)

- `Roads` renders merged asphalt + center-line ribbon meshes draped on terrain.
- Fixed avatar sinking into roads (offset 0.4 → 0.05) and center-line z-fighting.

## Avatar — Blender GLB
- `scripts/blender/build_character.py` builds a stylized humanoid (cream beanie,
  oversized hoodie, taupe cuffed pants, chunky sneakers, cup + tablet) and
  exports `public/models/character.glb` via Blender MCP.
- `GltfAvatar` animates named joint nodes; `PlayerModel` kept as procedural
  fallback behind a `PlayerAvatar` interface (ADR-0008).
- Fixed torso collapse: `animate()` was overwriting `JointTorso.position.y`
  (0.92); now bobs relative to the joint's base.
- Avatar is **static at rest**; animates only on input. Verified: limb rotations
  stay 0 and torso stays 0.92 when idle.

## Graphics fixes

## Audio — footsteps
- `src/audio/AudioManager.ts`: single WebAudio bus; synthesized footstep
  (filtered noise burst + envelope, randomized). Context resumes on first user
  gesture. `Player.onFootstep` fires once per PI of walk phase (per step, grounded
  only). Verified: 4 steps over 1.5 s walking; context state `running`.
- Foundation for later city ambience, birds, traffic, environmental loops (§57).
